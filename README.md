# 💳 UPI Transaction Data Analysis Web App

## 🚀 Project Overview
This project is an interactive UPI Transaction Analysis Web Application built using Python and Streamlit. 
It helps analyze transaction trends, success and failure rates, and bank performance.

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib / Seaborn

## 📊 Features
- Upload UPI transaction dataset
- Analyze successful vs failed transactions
- View bank-wise performance
- Monthly transaction trends
- Interactive charts

## ▶️ How to Run

1. Install requirements:
pip install -r requirements.txt

2. Run the app:
streamlit run app.py

## 🎯 Learnings
- Data cleaning using Pandas
- Building interactive dashboard using Streamlit
- Data visualization techniques
